# Galería de Fotos

Cada carpeta corresponde a un taller o actividad. Para agregar fotos, copiá las
imágenes dentro de la carpeta que corresponda y poneles un nombre secuencial
(`herreria-1.jpg`, `herreria-2.jpg`, etc.).

Las fotos deben tener formato `.jpg`, `.jpeg`, `.png` o `.webp`. Se muestran
automáticamente en la página de Galería.

## Estructura

| Carpeta                | Contenido                              |
|------------------------|----------------------------------------|
| `herreria/`            | Taller de Herrería y Soldadura         |
| `aire-acondicionado/`  | Instalación y Reparación de A/C        |
| `apoyo-escolar/`       | Apoyo Escolar y Terminalidad Educativa |
| `cocina/`              | Taller de Cocina y Salida Laboral      |
| `alfabetizacion-digital/` | Alfabetización Digital y Oficios    |
| `institucional/`       | Eventos, celebraciones y actividades generales |
